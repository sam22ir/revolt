# Painted icons

Round bronze medallions cut from `../source/icons-1.jpg`, generated by the user in Google Flow (Nano Banana 2.1) on 23 Nov 2026
with the bronze kit and the daylight camp concept as references (`docs/design/ui-pass-plan.md`). `../source/icons-1-alt.jpg` is
the other take from the same prompt, kept for reference.

Each is a 128 px PNG with a round alpha mask: `clock`, `lock`, `sword`, `shield`, `troops`, `wounded`, `storage`, `builders`,
`level_up`. Drawn with `UiKit.painted(name, size)`.
